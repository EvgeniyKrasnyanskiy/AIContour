- [Completed] **Сетевая стабильность клиента:** подключено моментальное сохранение IP-адреса в `config/client_settings.ini` при вводе; добавлен быстрый диалог смены IP по клику на статус-индикатор сервера.
- [Completed] **Единая очередь (Read-Only для чужих задач):** клиентская таблица синхронизирована с очередью сервера; задачи оператора выделяются cyan-цветом и меткой `[Этот ПК]`; для чужих задач отмена заблокирована.

- [Completed] **Сборка переносимого клиента:** успешная компиляция `ASS_Client.exe` и формирование портативного дистрибутива `dist/ASS_Client_Portable.zip` (103.16 МБ) с включенным `config/client_settings.ini`.
