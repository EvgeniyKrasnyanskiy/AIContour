# Дорожная карта проекта ASS (Auto Segmentation System)

Данный документ фиксирует стратегические этапы развития и текущие задачи системы автоматического оконтуривания органов риска.

---

## 📌 Версия 1.0 (Текущий этап — Ребрендинг, сетевая стабилизация и оптимизация КТ)

- [x] **1. Ребрендинг проекта в ASS (Auto Segmentation System)** [Completed]
  - Переименование заголовков окон, AppUserModelID, мьютексов предотвращения повторного запуска.
  - Обновление сборщиков PyInstaller (`build_clientPyQT5.py`, `build_clientPyQT6.py`, `.bat`).
  - Обновление DICOM AE Titles (`ASS_SCP`, `ASS_SCU`) с сохранением совместимости.
- [x] **2. Надежное сохранение IP-адреса сервера в клиенте** [Completed]
  - Немедленное автосохранение IP при вводе в `config/client_settings.ini`.
  - Удобный быстрый диалог смены IP по клику на индикатор статуса сервера.
  - Автовосстановление сессии и фонового опроса при восстановлении связи с сервером.
- [x] **3. Единая очередь задач оконтуривания на клиенте (Read-Only для чужих задач)** [Completed]
  - Отображение всех активных и выполненных задач очереди (со всех клиентов) в интерфейсе клиента.
  - Полный запрет на управление чужими задачами (отмена, приоритеты, паузы); разрешена отмена только своей активной задачи.
  - Визуальное выделение задач текущего рабочего места (`[Этот ПК]`).
- [x] **4. Корректная классификация структуры `body` в DICOM RTSTRUCT** [Completed]
  - Настройка DICOM-тегов `RTROIInterpretedType = "BODY"` и `ROIObservationDescription = "Type:Body,..."` для структуры тела (`body`).
  - Обеспечение распознавания структурой `Body` на планирующих станциях (Elekta Monaco, Eclipse, RayStation).
- [x] **5. Поддержка выноса рабочей папки temp для КТ на отдельный диск (RAM-диск / SSD)** [Completed]
  - Возможность задания кастомной рабочей директории временных файлов КТ в настройках/конфиге на сервере и клиенте.
  - Гарантированная очистка временных архивов и файлов после обработки.

## 🔮 Версия 2.0 (Кластеризация, автообновления и Zero-Config)
- [x] **Новая иконка приложения:** разработка и интеграция иконки (вид головного мозга сверху, визуально напоминающий женские ягодицы — обыгрывание аббревиатуры ASS) [Completed].
- [x] **Балансировщик нагрузки и кластер вычислений (Multi-Worker Cluster):** распределение ресурсоемких расчетов TotalSegmentator на CPU по пулу рабочих станций с 16 ГБ ОЗУ, роли Master-Worker, 3 политики балансировки, вкладка «⚡ Кластер» в GUI [Completed].
- [x] **Локальный центр обновлений (Centralized Auto-Update Hub):** раздача свежего `ASS_Client.exe` через Master-сервер без интернета, фоновое скачивание и бесшовный перезапуск в 1 клик [Completed].
- [x] **Zero-Configuration Deployment и UDP Auto-Discovery:** автоматическое обнаружение сервера в локальной сети больницы (порт 8001), 1-клик экспорт преднастроенного клиента `ASS_Client_Configured.zip` [Completed].
- [x] **Руководство системного администратора (`docs/ADMIN_GUIDE.md`):** сетевая топология, порты 8000/8001, Windows Firewall, кластер CPU 16 ГБ, безопасность данных [Completed].
